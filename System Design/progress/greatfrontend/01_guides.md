# Playbook Guides

The GreatFrontEnd System Design Playbook includes 6 comprehensive articles to help you prepare for front end system design interviews. 

## 1. Front End System Design: An Introduction
An overview of the useful techniques and how to approach top front end system design questions. Written by ex-interviewers at FAANG.

## 2. Types of Front End System Design Questions
Covers the different question formats you can expect in a front-end system design interview (e.g., UI Components vs. Application Design).

## 3. The RADIO Framework
A structured framework designed specifically to tackle front end system design problems:
- **R**equirements Exploration
- **A**rchitecture / High-level Design
- **D**ata Model
- **I**nterface Definition (API)
- **O**ptimizations and Deep Dives

## 4. Evaluation Criteria for Front End System Design Interviews
Specific behaviors and signals interviewers look out for, helping you understand how you are being graded.

## 5. Common Mistakes to Avoid
A collection of frequent mistakes candidates make during front end system design interviews and strategies on how to avoid them.

## 6. Cheatsheet for Front End System Design Interviews
A summary of the most important concepts and patterns you should take note of during your interviews.
