# Interview Preparation MOC

This module trains communication, not new mechanisms: it turns the knowledge from the core modules into answers that sound experienced under time pressure. Work through it by answering every question aloud before reading the model answer, then scoring yourself against the strong-answer signals. Return here weekly with the Mock Interview Guide until weak answers are upgraded, not just recognized.

## You're Done When

- [ ] You can answer every question in files 01-03 aloud in 60 seconds each, naming the accurate mechanism.
- [ ] You can define, explain the mechanism, trace an example, name a bug, and state a safe pattern for each checklist topic — not just recognize the term.
- [ ] You can write from memory: debounce, an ignore-flag effect, an `AbortController` effect, and a stale-interval fix.
- [ ] You can debug the classic bug set: `var` loop, extracted method losing `this`, mutated state skipping a render, stale search response.
- [ ] You have completed at least one full 45-minute mock session and scored 8+ on the self-scoring rubric.
- [ ] You can upgrade any weak answer using mechanism, example, consequence, and tradeoff without rambling.
- [ ] You have run the "Day Before Interview" routine once, including two real project stories.
